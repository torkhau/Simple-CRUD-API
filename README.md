# Simple CRUD API

### Prerequisites
1. Install [Node.js](https://nodejs.org/en/download/)   
2. Clone your newly created repo locally: https://github.com/torkhau/Simple-CRUD-API.git
3. Switch to `dev` branch
4. To install all dependencies use [`npm install`](https://docs.npmjs.com/cli/install)  
6. Run **start:dev** in command line.
7. You will see message `Server started at http://localhost:3000`.


In the future, we can use third-party software, such as [Postman](https://www.postman.com/), to test the application.

[Thunder Client](https://www.thunderclient.com/), an extension for VSCode, was used for testing during the development process.
